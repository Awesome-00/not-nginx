About this project

not-nginx is a minimal HTTP/1.1 server written in C, built directly on raw POSIX sockets - no libraries, no frameworks.

It reads a raw HTTP request off the socket, parses the method and path, routes based on path, and serves real HTML files off disk with a correctly built response (status line, headers, Content-Length, body). Unknown paths get a proper 404.

Built by following Beej's Guide to Network Programming for the socket fundamentals, then working out the HTTP layer from the raw protocol format.

Code / commands used

  • socket, bind, listen, accept - set up the TCP server
  • read / write - receive requests, send responses
  • strtok - parse method and path from the request line
  • strcmp - route requests by path
  • fopen / fread / fclose - read HTML files from disk
  • gcc httpserver.c -o httpserver - build
  • ./httpserver - run, then visit localhost:8080
